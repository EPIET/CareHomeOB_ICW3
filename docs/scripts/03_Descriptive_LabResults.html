CautionReady-to-export table, ready-to-reuse code

The code below notably improves the tbl_summary() output. It is also a more complex code that includes html and markdown notation using a glue approach. There is a chance none of those words were even familiar for you. And that’s ok, you don’t need to understand it right now.

What you need to understand is that, by copying this code, you can adapt it to all your future tables only by changing the name and amount of labels and headers, and that is valuable

## Quick way to see the percentage of cases among the total participants
janitor::tabyl(clean, case)

## Complete Table Summary of Age, Sex and Group counts
table1 <- clean %>% 
  # only columns of interest
  select(case, age, sex, group) %>% 
  tbl_summary(by = case,
              # modify row headers
              label = list(
                age ~ "Age",
                sex ~ "Sex", 
                group ~ "Group"
              )) %>% 
  bold_labels() %>% 
  # add total column
  add_overall() %>% 
  # customize header labels and appearance
  modify_header(
    label = "**Characteristic**",
    stat_0 = "**Overall** \n **N** = {n} ({style_percent(p)}%)",
    stat_1 = "**Non-case** \n **N** = {n} ({style_percent(p)}%)",
    stat_2 = "**Case** \n **N** = {n} ({style_percent(p)}%)", 
  ) 

# Export to Word using flextable
table1 %>% 
  as_flex_table() %>% 
  autofit() %>% 
  save_as_docx(path = here("outputs", "Table_1.docx"))

We know about the median ages and sex distribution of cases and non-cases, but we should explore further to find potential differences for example between residents of the care home and their families. We can do that with both a table and a boxplot:

Action — Cross-tabulate age and sex by group using tbl_summary(). Don’t worry about exporting this one.

CautionSee the solution 
# Table with Age and Sex distribution among residents and family members
clean %>% 
  select(group, age, sex) %>% 
  tbl_summary(by = group)

# Violin plot of age among residentes and family members
clean %>% 
  ggplot(aes(x = group, y = age)) +
  geom_violin() +
  theme_bw()

Person: Symptoms by Case Definition

Action — Produce a summary table displaying the symptoms among cases and non-cases. Probably you can recycle the vector you created to clean these columns for this task. Which symptom was the more common among cases?

Extra! — Create a bar-plot of symptom’s frequency among cases (only if you have time later on)

CautionSee the solution 
# Table summary of symptom distribution by case definition
clean %>% 
  select(all_of(symptoms), case) %>% 
  tbl_summary(by = case) %>% 
  bold_labels() %>% 
  italicize_labels()

# Barplot of symptom distribution among cases
clean %>% 
  select(symptoms, case) %>% 
  # we need to pivot to long format for the counts
  pivot_longer(
    all_of(symptoms),  
    names_to = "symptom",
    values_to = "present"
  ) %>% 
  # only interested in symptoms among cases
  filter(present == "Yes", 
         case == 1) %>%    
  # Start of the graph
  ggplot(aes(
    # this trick arranges categories by frequency automatically 
    y = fct_infreq(symptom))
    ) +
  geom_bar(fill = "darkred",   # some aesthetics
           alpha = 0.70) +
  labs(x = "Number of cases",  # custom labels
       y = "") +
  # predefined theme, as always
  theme_minimal()

# Epicurve with datetime customization
clean %>%  
  # Only cases
  filter(case == 1) %>% 
  # Add factor onset_datetime to ggplot aesthetic:
  ggplot(aes(x = onset_datetime)) + 
  geom_histogram() +
  # select 6h breaks with custom date-time labels
  scale_x_datetime(

            by = "id")

Not every case has a positive test result. That is perfectly fine and common, as microbiology sampling is subject to limitations such as the time elapsed from clinical onset until collection, sensitivity, and other limitating factors. In this outbreak, laboratory confirmation was not part of the Case Definition and, therefore, this information remains confirmatory of the causative agent of the outbreak.
